# 发动机RUL预测系统 - 功能说明

## 🎯 系统概述

本系统使用LSTM神经网络对发动机的剩余使用寿命（RUL）进行预测。通过对100台发动机的历史监测数据进行学习，建立预测模型，能够准确预测发动机的剩余使用周期。

---

## 📊 核心功能

### 1. 数据处理与预处理

#### 功能描述
- **数据加载**：自动加载训练集、测试集和真实RUL值
- **编码处理**：自动处理多种文件编码格式（UTF-8、Latin-1等）
- **数据标准化**：使用Z-score标准化方法对所有传感器数据进行标准化
- **特征提取**：选择21个传感器特征作为模型输入

#### 技术细节
```
输入：原始CSV数据（26列）
处理步骤：
  1. 加载数据
  2. 提取21个传感器特征（列6-26）
  3. 使用StandardScaler进行Z-score标准化
  4. 创建时间序列（30个时间步）
输出：标准化的时间序列数据
```

#### 数据统计
- 训练集：20,631条记录，100台发动机
- 测试集：13,096条记录，100台发动机
- 特征数：21个传感器
- 时间序列长度：30个时间步

### 3. 模型训练与预测

#### 3.1 LSTM模型架构
```
输入层
  ↓
LSTM层1: 64个单元，ReLU激活，返回序列
  ↓
Dropout: 0.2（防止过拟合）
  ↓
LSTM层2: 32个单元，ReLU激活
  ↓
Dropout: 0.2
  ↓
全连接层: 16个单元，ReLU激活
  ↓
输出层: 1个单元（RUL预测值）
```

#### 3.2 训练配置
| 参数 | 值 | 说明 |
|------|-----|------|
| 优化器 | Adam | 自适应学习率 |
| 损失函数 | MSE | 均方误差 |
| 批次大小 | 32 | 每次更新的样本数 |
| 训练轮数 | 50 | 最大训练轮数 |
| 验证集比例 | 20% | 用于验证的数据比例 |
| 早停耐心 | 10 | 无改进时停止的轮数 |

#### 3.3 预测过程
```
测试数据
  ↓
提取最后30个时间步
  ↓
数据标准化
  ↓
LSTM模型预测
  ↓
输出RUL预测值
```

---

### 4. 模型评估

#### 4.1 评估指标

**RMSE（均方根误差）**
- 公式：√(Σ(预测值-真实值)²/n)
- 当前值：28.54周期
- 解释：平均预测误差约为28.54周期

**MAE（平均绝对误差）**
- 公式：Σ|预测值-真实值|/n
- 当前值：21.13周期
- 解释：平均绝对偏差约为21.13周期

**相对误差**
- 计算：RMSE / 平均RUL值
- 当前值：约30%
- 评价：预测精度良好

#### 4.2 性能评价
- ✅ RMSE 28.54周期：良好
- ✅ MAE 21.13周期：良好
- ✅ 相对误差30%：可接受
- ✅ 预测趋势准确：能有效捕捉RUL下降趋势
