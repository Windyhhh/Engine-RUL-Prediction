# 发动机RUL预测系统 - 使用说明

## 📋 快速开始

### 1. 环境要求
- Python 3.8+
- TensorFlow 2.x
- Pandas、NumPy、Scikit-learn
- Matplotlib、Seaborn

### 2. 安装依赖
```bash
# 使用pip安装
pip install tensorflow pandas numpy scikit-learn matplotlib seaborn

# 或使用conda
conda install tensorflow pandas numpy scikit-learn matplotlib seaborn
```

### 3. 运行程序
```bash
python main.py
```

程序会自动执行以下步骤：
1. 加载数据（训练集、测试集、真实RUL值）
2. 数据预处理和标准化
3. 生成可视化图表
4. 构建和训练LSTM模型
5. 进行RUL预测
6. 计算性能指标
7. 生成预测结果图表

## 🔧 参数调整

### 修改序列长度
在 main.py 中找到以下行：
```python
sequence_length = 30  # 修改此值，如20、40、50等
```

### 修改模型架构
在 main.py 中找到模型构建部分：
```python
# 增加LSTM单元数
model.add(layers.LSTM(128, activation='relu', ...))  # 从64改为128
model.add(layers.LSTM(64, activation='relu', ...))   # 从32改为64
```

### 修改训练参数
```python
epochs = 100  # 增加训练轮数（默认50）
batch_size = 16  # 减小批次大小（默认32）
```

### 修改Dropout比例
```python
layers.Dropout(0.3)  # 增加正则化（默认0.2）
```

## ⚠️ 常见问题

### Q: 程序运行很慢？
**A:** 这是正常的。LSTM模型训练需要时间，特别是在CPU上。
- 可以使用GPU加速（需要CUDA支持）
- 或减少训练轮数进行测试

### Q: 如何使用自己的数据？
**A:** 
1. 准备相同格式的CSV文件（26列）
2. 修改 main.py 中的文件名
3. 运行程序

### Q: 如何改进预测精度？
**A:** 可以尝试：
- 调整LSTM层数和单元数
- 修改序列长度
- 增加训练轮数
- 进行更多特征工程

### Q: 如何保存训练好的模型？
**A:** 在 main.py 中添加：
```python
model.save('rul_model.h5')
```

### Q: 如何加载已保存的模型？
**A:**
```python
from tensorflow.keras.models import load_model
model = load_model('rul_model.h5')
```

## 🚀 性能优化建议

1. **使用GPU加速**
   - 安装CUDA和cuDNN
   - TensorFlow会自动使用GPU

2. **减少数据量进行测试**
   - 修改代码只使用部分数据
   - 快速验证模型效果

3. **调整批次大小**
   - 较小的批次（16）：更新频繁，可能更准确
   - 较大的批次（64）：训练更快，但可能欠拟合

4. **使用早停机制**
   - 已在代码中实现
   - 防止过度训练
